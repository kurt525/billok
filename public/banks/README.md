# Логотипы банков BillOK

Источник: https://github.com/melpnz/rblp — каталог dark/svg/icon/, дата копирования 28.10.2026.

Файлы восьми банков используются исключительно для идентификации банка при выборе реквизитов СБП. Имена, логотипы и другие товарные знаки принадлежат соответствующим правообладателям. BillOK не связан с банками и не является их партнёром или официальным приложением. Набор rblp не предоставляет отдельной лицензии на знаки банков; при обращении правообладателя оформление может быть заменено или удалено.

Все восемь файлов проверены на отсутствие JavaScript, обработчиков событий, внешних ссылок и встроенных ресурсов. Сетевых запросов к банкам или источнику логотипов во время работы приложения нет. Нельзя использовать логотип как подтверждение счёта или операции.
