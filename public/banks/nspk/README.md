# Каталог и изображения банков

Снимок каталога: https://github.com/eav93/sbp/blob/main/data/banks.json от 2026-10-28T09:21:48.987Z. Данные получены исходно из реестра НСПК c2bmembers.json для оплаты по QR. Наличие банка в каталоге не означает, что его клиенты принимают переводы физлицам по номеру телефона.

Изображения WEBP 256x256: https://github.com/sbp-icons/sbp-icons (снимок 28.10.2026). Файлы 177 дополнительных банков размещены локально без стороннего CDN. Для 8 ранее существовавших банков сохранены локальные SVG. Для 10 записей без WEBP — текстовые обозначения.

Изображения и наименования являются товарными знаками соответствующих правообладателей; их появление не означает разрешение на произвольное использование, партнёрство или одобрение банка. Источник sbp-icons специально предупреждает об отсутствии предоставления прав на товарные знаки. При правомерной претензии изображение требуется удалить или заменить. Не обозначать знаком банка подтверждённый платёж.

## Автоматизированная сверка

После включения изменений PR #3 в основную ветку GitHub Actions запускает
.github/workflows/sbp-bank-catalog-sync.yml ежедневно в 05:20 UTC
(08:20 по московскому времени), а также вручную через workflow_dispatch.
Обновление берётся только из eav93/sbp/data/banks.json.

- Новые участники добавляются с текстовой меткой до подготовки иконки.
  Устаревшие записи остаются для ранее сохранённых настроек профиля,
  но скрыты из нового выбора и помечены в интерфейсе как неактуальные.
- Переименования обновляют отображаемые названия по стабильным ID НСПК.
  Для первоначальных восьми банков сохранены внутренние ID BillOK.
- Ошибочные данные, дубликаты и аномально массовые удаления
  останавливают синхронизацию с ошибкой.
- Изменение даты публикации без изменений перечня не создаёт коммита.
  При реальном изменении автоматически готовится отдельный PR и запускается
  полный CI через workflow_dispatch. Слияние и выкладка не автоматические.
- Для создания автоматических PR в настройках Actions репозитория должны
  быть разрешены операции GitHub Actions по созданию pull requests.

Сверка каталога НСПК выявляет изменения состава QR-участников, но сама по себе
не устанавливает наличие или утрату банковской лицензии и не удостоверяет
возможность перевода физлицу по номеру телефона.
