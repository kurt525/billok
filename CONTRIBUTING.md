# Участие в разработке BillOK

BillOK — русскоязычное приложение для ручного разделения чеков. Проект пока не опубликован: данные и учётные записи на этапе разработки тестовые. Требования и порядок приёмки — Issue #1 (https://github.com/kurt525/billok/issues/1), журнал изменений и CI — PR #3 (https://github.com/kurt525/billok/pull/3).

Проект основан на ShareTab (MIT), но прежние инструкции upstream не описывают выпуск BillOK.

## Среда разработки

Требуются Node.js 22.23.4, npm, PostgreSQL и Chromium для Playwright. Используйте отдельную тестовую БД и только тестовые значения окружения. Команды для локальной среды:

    git clone https://github.com/kurt525/billok.git
    cd billok
    npm ci --legacy-peer-deps
    npx prisma generate
    cp .env.example .env

Заполните локальный .env тестовыми параметрами. Настоящие пароли SMTP, токены, секреты и данные других сервисов не копировать.

    npx prisma db push
    npm run dev

Команда npm run dev:full запускает встроенную тестовую PostgreSQL и Next.js. Тестовые записи создаются только в изолированной QA-БД через BILLOK_QA_FIXTURES=1 npm run db:seed. Они не заменяют регистрацию по приглашению с подтверждением email и Passkey.

## Проверки

    npm run lint:i18n
    npm run lint
    npm run format:check
    npx tsc --noEmit
    npm test
    python3 scripts/test_billok_legacy_cleanup.py

Проверка npm run lint:i18n контролирует единственный каталог messages/ru: непустые переводы, отсутствие старого бренда и ненужных локалей. Языковой переключатель и дополнительные языки BillOK не поддерживает.

Обязательный workflow .github/workflows/billok-ci.yml содержит пять заданий: Vitest, Code quality/types, Coverage regression, Mobile Chromium (320–720 CSS px) и BillOK mobile PWA. Полный CI запускается после точечных проверок. Случайно упавшее задание повторяется без дополнительного коммита.

## Архитектура и границы изменений

- Только ручные чеки, суммы в RUB до копейки, доли, один плательщик и добровольные чаевые.
- Только Passkey для зарегистрированных пользователей, приглашение и подтверждение email. Пароли, Magic Link, Google и OIDC запрещены.
- Только русский интерфейс и мобильные сценарии.
- Страница /groups/[groupId]/scan является действующим ручным редактором, несмотря на историческое имя.
- Серверные маршруты: src/server/trpc/routers/; UI: src/app/ и src/components/; схема: prisma/.
- Prisma, SQL, сброс тестовой БД, предрелизные проверки и публикацию выполнять в отдельных разделах Issue #1. Рабочую БД не сбрасывать.

Сохраняйте проверки прав, транзакционные блокировки, копейки и атомарное назначение долей. Не допускайте изменения чужих сервисов VPS.

## PR и безопасность

Работайте через ветку PR #3; не отправляйте изменения прямо в main, не переписывайте историю и не создавайте лишние коммиты. В Issue #1 — только задания и checkbox их приёмки, в PR #3 — описание реализации и результаты CI на русском языке.

Не помещайте секреты в Git, CI-логи или артефакты. Не удаляйте установленный Node.js 22.23.4 на ci-runner. Production-развёртывание и создание рабочей учётной записи владельца — только после отдельной приёмки и разрешения.

Документы для операторов: ops/billok/PRODUCTION-SECRETS.md и ops/billok/HTTPS-PREDEPLOY.md.
