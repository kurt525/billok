# BillOK

BillOK — русскоязычный self-hosted сервис ручного разделения счетов, групповых расходов и взаиморасчётов. Проект находится в разработке и ещё не развёрнут для пользователей на billok.ru.

BillOK основан на [ShareTab](https://github.com/sw-carlos-cristobal/sharetab) Карлоса Кристобаля. Лицензия исходного проекта — [MIT](LICENSE).

## Возможности

- Ручное создание групповых чеков без фотографий, OCR, моделей ИИ и платных AI API.
- Позиции, количество и цена в рублях; назначение участников, распределение по фактически употреблённым частям.
- Сохранение незавершённого чека, просмотр сумм в копейках и выбор плательщика.
- Группы, приглашения, расходы и взаиморасчёты.
- Участие в существующей гостевой ссылке без регистрации; создание нового чека — после авторизации.
- Единственный пользовательский язык — русский; мобильный веб-интерфейс и PWA для Android.
- Администрирование пользователей, регистраций и журнала действий.

**Распознавания чеков нет.** Старые функции AI/OCR, настройки провайдеров и API загрузки изображений для распознавания исключены. Установка локальных моделей на VPS не требуется.

## Требования

Node.js 22, PostgreSQL, npm. Для проверки интерфейса используется Playwright Chromium. Для разработки и CI нужна изолированная тестовая БД: нельзя запускать seed-скрипты на production.

## Локальный запуск

1. Скопируйте .env.example в .env; настройте DATABASE_URL, AUTH_SECRET, NEXTAUTH_SECRET и при необходимости SMTP.
2. Установите зависимости: npm ci --legacy-peer-deps.
3. Сгенерируйте Prisma Client: npx prisma generate.
4. Подготовьте базу: npx prisma db push (только для соответствующего окружения).
5. Запустите веб-приложение: npm run dev.

## Docker

В docker/docker-compose.yml есть контейнер с приложением и PostgreSQL. Настройте секреты в docker/.env и храните их вне Git. Для запуска:

    cd docker
    docker compose up -d --build

Docker не устанавливает AI-провайдеры, Claude Code, ChatGPT OAuth-модели или зависимости OCR.

## Проверки

    npm run lint:i18n
    npm run lint
    npx tsc --noEmit
    npm test
    python3 scripts/test_billok_pwa.py

Ветка разработки проверяется GitHub Actions с изолированной PostgreSQL и мобильным Chromium (320–412 px). Данные CI не предназначены для production.

## Безопасность

Не добавляйте секреты, реальные адреса пользователей, ключи SMTP или содержимое баз данных в Git. Резервное копирование и миграции действующего окружения выполняются отдельно от разработки.
